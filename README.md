# AI Dev Tools Zoomcamp 2026

Coursework for the DataTalksClub AI Dev Tools Zoomcamp 2026.

## TaskFlow

TaskFlow is a full-stack task management application developed
through multiple course modules. Each module extends the previous
work, progressing from application delivery to operational
reliability and AI agent tooling.

### Development Across Modules

- [Module 3 — Test, Containerize, and Deploy TaskFlow](./module-3/)
  Full-stack application, PostgreSQL, migrations, integration tests,
  Docker containers, CI/CD, and AWS deployment.

- [Module 4 — DevOps and Observability for TaskFlow](./module-4/)
  Release management, DEV/PROD promotion, observability, alerting,
  bounded AI-assisted incident investigation, authorization,
  recovery verification, and security review.

- [Module 5 — Agent Extension Pack](./module-5/)
  Repository-scoped AI agent tooling for API contract review,
  including reusable Skills, a specialized read-only reviewer,
  an allowlisted MCP server, a plugin package, and security guardrails.

Module 5 extends the development workflow without changing
the established TaskFlow application behavior or deployment
architecture from Modules 3 and 4.
